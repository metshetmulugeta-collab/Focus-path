# FocusPath - Distraction-Free Student Dashboard

FocusPath is an interactive web dashboard designed to eliminate digital distractions and provide transparent academic guidance for high-achieving students, especially those in smaller towns who lack access to international admissions information.

## 🚀 The Problem I Noticed
In my city, many capable students lose focus due to social media distractions or struggle with finding structural study methods. Furthermore, highly talented students from smaller towns often lack critical information on how international university scholarships work, leaving them excluded from global opportunities.

## 🛠️ Features
- Focus Zone (Pomodoro Timer): A built-in 25-minute study sprint timer built with JavaScript to foster deep focus habits and block external noise.
- Scholarship Roadmap: A structured breakdown detailing holistic admissions criteria (Grades, Leadership, and Innovation) required by top global universities.

## 💻 Tech Stack
- HTML5: Structured semantic layout for distraction-free reading.
- CSS3: Calm, modern dark-mode interface designed to reduce eye strain.
- JavaScript (ES6): Real-time interactive countdown timer logic.
